# Contributing

A chapter should contain learning objectives, a motivating question, MATLAB-first worked examples, a reproducible experiment, a system constraint discussion, exercises, and references. A lab should specify software, optional hardware, reproducibility metadata, expected artifacts, and one measured outcome.

Avoid checking in generated `codegen` builds, MAT model files, or private datasets. Document toolbox and hardware requirements precisely. MATLAB results must be verified in MATLAB; the Quarto CI validates only documentation generation. Before redistribution, establish licensing for the contributed tutorial, recordings, figures, and generated artifacts.
