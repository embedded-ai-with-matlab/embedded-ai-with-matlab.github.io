# Arduino Nano 33 BLE Sense Rev1

The full worked vibration example is in `../../matlab/projects/vibration-severity-monitor/arduino/`. This project uses the **Rev1 LSM9DS1 IMU** and the `Arduino_LSM9DS1` library. It is not a drop-in deployment for Rev2. Generated `src/model` C/C++ files must be produced by the MATLAB code-generation stage before compiling the sketch. Consult the attached project's README before flashing.
